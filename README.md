# 花园 / Flower garden

A DSH session view where you grow twenty-five real flowers across four grounds, greet the bees and birds that visit them, and follow a daily flower market.

会话视图里的养花游戏：草原、雪原、火山口、湖畔四块地，二十五种真实花卉，按真实形态绘制、按真实时间生长；开着的花会引来访客授粉，每天有一种花是花市行情，还有成就可以慢慢完成。

## Where it appears / 出现位置

A **Garden (花园)** tab joins the session view tab row next to Chat and
Trajectory once a session has started. Blank sessions show no tabs, so send a
first message (or pick a workspace) to see it.

会话开始后，视图标签栏（Chat、Trajectory 旁边）多出 **花园** 标签。空白会话不显示
标签栏，发一条消息或选好工作目录后即可看到。

## The loop / 玩法循环

1. **播种** — 在花地上选种子，扣金币，土壤浇水满。
2. **浇水** — 免费补满湿度；一次浇透大约能长到七成半，之后干了生长暂停。
3. **收获** — 开花后收进**花篮**（12 格），收获给经验。
4. **查看 / 卖出** — 点花篮里的花会展开这朵花的详情（大图、学名、花语、单价与合计），在详情里按当前花市报价卖出（点两次确认）；或凑成**花束委托**交付，拿更多金币。
5. **道具** — 金币买肥料、洒水器、幸运符，以及花篮扩容。
6. **开地** — 金币解锁新花地和新花圃。
7. **图鉴** — 每款花第一次收获后解锁花语与学名；点卡片上的花或款式标签，可以打开标本弹窗看这一款的样子（含学名、花语、收获次数）。
8. **访客** — 开着的花会引来访客，点它打招呼：拿小费，这朵花被授粉，收获时多得一朵。
9. **花市 / 成就** — 每天一种花卖价 +50%；十六个成就按进度发金币。

## Living garden / 个体、育种与持续经营

- **每株独立外观**：播种生成固定的 DNA，高矮、朝向、倾斜、花瓣与色彩有细微差异；收获进花篮仍保留这株的外观，刷新不会重抽。
- **奇珍**：多次访客、多次施肥、缺水经历、特定天气或深夜收获可能产生并蒂、巨株、斑锦、墨玉、霜晶、熔火、虹彩、珠光。条件只提供机会，不保证出现。花篮分开保存奇珍与普通花，支持组内个体切换和单株出售；送展也可选择具体植株。普通花束不会消耗奇珍或杂交花。
- **杂交种子**：已授粉的花收获时，左右相邻编号的花圃若有另一种盛开的花，基础 45% 概率结一粒杂交种子。种子保留母本株型、使用邻花颜色，在母本所属花地的播种列表免费播种。
- **地力**：每次收获消耗 14；连种同种再减 10，轮种其他品种加 8；空地每分钟恢复 1。贫瘠地块最低以正常速度的 55% 生长。商店的堆肥 25 金币一袋，在花圃使用恢复 60 地力。
- **花市饱和**：同种花每售出一朵，后续价格下降 5 个百分点，最低为原价 50%；每 2 分钟恢复一档。批量卖出逐朵报价，花篮和卖出使用相同算法；各分组报价是单独卖出价，全部卖出采用总报价。
- **花展**：每 6 小时一期主题展，最多送 8 朵。点击送展后再次确认，花会消耗并换评分，不发金币。达到 6 / 14 / 24 分时分别获得 1 / 2 / 3 条绶带，一届最多 6 条。
- **设施**：蜂箱提高访客概率，温室提高奇珍机会，育种台提高结杂交种子的概率。每种最高 8 级，价格按 ×1.8 增长，第二级起同时消耗绶带。消耗品、育种和周期花展提供持续目标；这不意味着金币总量有硬上限。
- **图鉴弹窗**：普通款式和已收集的奇珍、杂交花均可打开标本卡，查看学名、花语、植物知识与形成原因；支持切换条目、查看不同个体示例、Esc 关闭。新收获会保存该完整类型的首株真实标本（含 DNA、花色、奇珍和杂交组合），出售后仍保留；旧版只有计数的条目显示标准株。外观示例与收藏标本明确区分。

## Visitors, market, achievements / 访客、花市、成就

**访客授粉。** 每个开花的花圃每 45 秒有 34% 的机会来一位访客（由时钟确定，不用计时器，刷新页面不变）。
点花上方的圆形按钮打招呼：得小费、这朵花标记为「已授粉」，收获时在花篮有空位的情况下**多得一朵**
（第二朵是花圃本来的花色，不会是仙品）。所以开花后可以等一等再收。

| 访客 | 出现在 | 时间 | 小费 |
| --- | --- | --- | --- |
| 蜜蜂 | 草原 / 火山口 / 湖畔 | 白天 | 2 |
| 菜粉蝶 | 草原 / 湖畔 | 白天，不下雨 | 3 |
| 七星瓢虫 | 草原 | 全天 | 3 |
| 蜻蜓 | 湖畔 | 白天，不下雨 | 4 |
| 萤火虫 | 草原 / 湖畔 | 夜里 19:00–06:00 | 5 |
| 蜂鸟鹰蛾 | 草原 / 火山口 / 湖畔 | 夜里 | 6 |
| 知更鸟 | 雪原 | 全天 | 5 |
| 镰嘴管舌雀 | 火山口 | 白天 | 8 |
| 翠鸟 | 湖畔 | 白天（少见） | 12 |

**今日花市。** 每天本地零点换一种「行情花」，卖价 ×1.5（与别色 ×1.3、仙品 ×3 相乘），只从已解锁花地的花里选；
花束委托的报酬不变。标题栏的「今日花市」标签和花篮里的「行情」标记会提示。

**成就。** 十三个长线目标（累计收获、访客、授粉、交付委托、仙品、图鉴、开地），完成后在「成就」里点领取，
奖励 10 ~ 1500 金币。有可领取的成就时，折叠状态下也会直接露出来。

**一键浇水。** 当前花地有两株以上缺水时，花圃标题右侧出现「全部浇水」。

## Four grounds / 四块花地

| 花地 | 解锁 | 对天气的反应 |
| --- | --- | --- |
| 草原 Meadow | 初始 | 晴 +15%、阴 如常、雨 土壤自动湿润 |
| 雪原 Snowfield | 150 金币 | 晴雪 +5%、阴雪 −5%、降雪 湿润但 −10% |
| 火山口 Crater | 450 金币 | 热浪 +25%、硫雾 −10%、落灰 −15% 且**不**湿润 |
| 湖畔 Lakeside | 1200 金币 | 晴 +10%、薄云 +5%、细雨 +20% 并湿润 |

每块地 6 个花圃，初始开 3 个，另外 3 个按 40 / 90 / 160 金币依次解锁。天气每 5 分钟
换一次，按时间种子确定，所以同一时刻永远是同一种天气；离线补算也按天气分段精确积分。

每种花有自己的绘制函数（`client.js` §5 的 `PLANTS`），按整株形态而不是只画花头：花瓣从基部到
尖端有明暗渐变和中脉，叶片有叶脉，茎有受光面，四块地各有自己的地面（土、雪、熔岩、水面）。

- 草原：蒲公英是四圈舌状花 + 倒向羽裂的莲座叶；雏菊白瓣尖端泛粉；樱花开在带短枝的木质枝条上，
  花瓣有缺刻；郁金香是五片可见花被围成的杯；薰衣草一丛三穗、轮伞花序；虞美人四片皱瓣带黑斑，
  旁边垂着花苞；向日葵花盘按黄金角排小花；百合六枚花被 + 锈色大花药，叶沿茎互生；玫瑰四层卷瓣、
  带刺、羽状复叶；绣球是受光的小花球。
- 雪原：雪滴花花葶弯垂、内花被有绿斑；铁筷子五枚萼片、绿色蜜腺和一团雄蕊，掌状叶；梅花圆瓣长蕊、
  先花后叶；雪绒花是长短不一的毡毛苞片围着一簇小头状花序；山茶重瓣金蕊、革质亮叶。
- 火山口：仙人掌是带刺座的掌片，花开在掌缘，旁边有果；红火山花没有花瓣，只有雄蕊绒球；龙舌兰是
  带刺莲座 + 分枝的高花葶；银剑草是银色叶球 + 一柱酒红色头状花；鸡蛋花是蜡质风车花簇，粗枝带叶痕。
- 湖畔：梭鱼草蓝紫穗 + 心形箭叶；千屈菜是六瓣小花的尖塔；黄菖蒲三枚垂瓣带褐色脉纹；睡莲浮叶有
  缺口，花贴水面；荷花高出水面，花瓣基部白、尖端粉，露出莲蓬，旁边一片盾形叶。

种子 → 幼苗 → 花苞 → 开花四个阶段都是同一株植物：花苞期已经是这种花自己的株型。

## Items / 道具

| 道具 | 价格 | 作用 |
| --- | --- | --- |
| 堆肥 Compost | 25 | 对一个花圃使用：恢复 **60 地力**，最高 100 |
| 肥料 Fertiliser | 35 | 对一株花使用：瞬间推进 **25%** 生长（不会越过开花） |
| 洒水器 Sprinkler | 90 | 对**当前花地**使用：30 分钟内整块地自动保湿，土壤不再变干 |
| 幸运符 Lucky charm | 120 | 启用后**下一次收获**仙品概率 +25%（与其它加成叠加，上限 55%），无论是否出仙品都会消耗 |
| 花篮扩容 Basket upgrade | 150 | 花篮 12 → **18** → **24** 格，最多 2 次 |

花篮按花种、花色、奇珍特征和杂交亲本分组，每一组花都可以点开看：详情面板里是这朵花的完整插画（仙品带光晕和星芒）、学名、花语、
单价与合计，卖出按钮就在面板里，避免误点。图鉴里**收获过的**花也一样——点卡片上的花或「原色／别色／仙品」
标签，就会打开标本弹窗（这朵花的插画、学名、花语和收获次数），没收到过的仍是剪影。

用法：肥料会在有花的花圃上多出一个「施肥」按钮；洒水器/幸运符在「道具」面板里点「对本地使用」／「启用」；
花篮扩容购买后立即生效。洒水器运行时，花地标题旁会显示剩余时间，花圃状态改为「湿 100%」且不再提示干透。

## Variants and the hidden bloom / 花色与隐藏款

每种花在图鉴里有 2~3 条款目：

| 款 | 怎么来 | 卖价 |
| --- | --- | --- |
| 原色 | 双数花圃开花 | ×1 |
| 别色 | 只在 **#1 / #3 / #5** 号花圃开花（15 种花有自然别色） | ×1.3 |
| 仙品（隐藏款） | 收获时随机触发 | ×3 |

仙品外形是**通体发光**的：珍珠白到淡紫的渐变花瓣、身后的柔光晕、缓慢自转的虚线圈、
四角星芒和上浮的光点（`prefers-reduced-motion` 下静止）。概率 = 基础 **3%**，再叠加：整株**从未缺水** +7%、在**本地偏爱的天气**里收获 +5%、
**刚浇过水**（湿度 ≥80%）+8%、**夜里**（22:00–05:00）收获 +7%，上限 **30%**。图鉴里会
写明这条线索。仙品不参与花束交付，可以卖出（基础 3 倍价，仍受行情与饱和影响）或送展。

## Limits / 说明

- The garden is stored in this browser's `localStorage` for the running profile
  (`dsh.flower-garden.v4`) and is shared by every session. It is not part of the
  session log, so it does not travel with a session export or a fork. A v1, v2 or v3
  garden is migrated on first load (coins, experience, plots, and every flower already recorded);
  a v4 garden saved before visitors and achievements simply starts those counters at zero.
- Nothing is sent anywhere: no model request, no tool call, no network access.
- Turning the plugin off removes the tab and keeps the saved garden.
- Progress is per browser: two windows that both show the garden overwrite each
  other's save in last-write-wins order.

花园进度保存在当前运行环境的浏览器 `localStorage`（`dsh.flower-garden.v4`），所有
会话共用，不写入会话日志，因此不会随会话导出或 fork 一起迁移。旧版存档
（v1/v2/v3）首次加载时迁移：金币、经验、花圃和已收集的花都会保留，旧记录记为「原色」。
插件不发任何模型请求、工具调用或网络请求；关闭插件只会隐藏标签，花园数据仍然保留。

## Development / 本地开发

```bash
npm install          # 只为跑测试和生成预览图（react / react-dom 是 devDependencies）
npm test             # 数值断言 + 静态渲染断言
npm run preview      # 用游戏同一套绘制代码重新生成 docs/preview.svg
```

项目结构：

```
package.json        bundle 清单（dsh.bundle + dsh.client）+ 测试脚本
cordis.patch.yml    插入 flower-garden 插件行
index.js            Host 半边：无行为，只负责让插件行可解析
client.js           浏览器半边：花园视图、场景、规则、绘制、样式
locale/*.json       插件管理页的标题 / 描述 / 详情文档
docs/               一张预览图（由同一套绘制代码生成）
test/               数值检查 + 渲染检查
tools/preview.cjs   预览图生成器
```

安装到 DSH：在 DSH 的 **设置 → 插件 → 添加插件** 里选择本目录（本地目录安装是
link）。本目录提供直接加载的 client.js；实际生效还取决于当前 DSH 的客户端构建与缓存，需在已运行的 DSH 页面刷新后验证。

The preview image in `docs/preview.svg` was generated from the same `FlowerArt`
code the view renders — one flower from each ground.
