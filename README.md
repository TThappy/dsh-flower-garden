# 花园 / Flower garden

A DSH session view where you grow fifty-three real flowers across six grounds, greet the bees and birds that visit them, and follow a daily flower market.

会话视图里的养花游戏：草原、雪原、火山口、湖畔、林地、荒漠六块地，五十三种真实花卉，按真实形态绘制、按真实时间生长；开着的花会引来传粉、护园和水岸访客，每天有一种花是花市行情，还有成就可以慢慢完成。

## Where it appears / 出现位置

A **Garden (花园)** tab joins the session view tab row next to Chat and
Trajectory once a session has started. Blank sessions show no tabs, so send a
first message (or pick a workspace) to see it.

会话开始后，视图标签栏（Chat、Trajectory 旁边）多出 **花园** 标签。空白会话不显示
标签栏，发一条消息或选好工作目录后即可看到。

花园顶部的 **花园小窗** 按钮可打开应用内悬浮花园；随后切回 **Chat**，仍能一边对话一边看花。小窗和主花园共用存档，支持切换已解锁花地、浇水、普通播种、施肥、收获、留园和招呼访客，也显示仙品、奇珍和杂交外观。访客以插画图标出现在花朵旁，点击即可打招呼并领取对应奖励。拖动标题栏移动，拖动右下角调整大小；标题和缩放手柄支持方向键。可以收起为标题条或关闭，关闭小窗不删除进度。小窗位置和开关仅在本次打开期间保留。

要在切换应用后继续看花，打开 **花园小窗 → 放到桌面**。桌面窗口可以拖动并保持置顶。在桌面浇水或收获时，操作会同步到打开小窗的 DSH 页面。使用期间请保持该页面打开，主窗口可以最小化。首次从源码安装时，在项目目录运行 `npm install` 和 `npm run desktop:setup`，为当前系统准备 Electron 桌面运行时（需要 Node.js 22.12 或更高版本）。

## Tabs, typography and time / 标签页、字体与时间

花园按功能分为九个标签：**花园、花篮、委托、生态研究、花展与设施、道具商店、花卉图鉴、访客图鉴、设置与成就**。顶部标签栏独立于内容滚动，窄窗口可横向滚动标签；支持左右方向键以及 Home / End。每页的滚动位置在本次打开期间分别保留，当前标签随存档保存。

顶部可直接切换 **13 / 15 / 17 / 19px** 四档文字大小；「设置与成就」还能选择系统、衬线或圆润字体。默认 15px，界面正文、按钮和弹窗按比例缩放；字体使用设备已有字库，不下载外部资源。设置随浏览器存档保存，旧档自动补默认值。

顶部与花园全景均显示设备本地日期、24小时制时分秒、IANA 时区及时段，每秒更新：05:00–07:00 清晨、07:00–11:00 上午、11:00–14:00 中午、14:00–17:00 下午、17:00–19:00 傍晚，其余为夜晚。它与访客使用同一设备时钟，不代表真实日出日落计算；天气仍是游戏模拟。

花地采用分层 SVG 全景插画：草坡远山、积雪松林、火山岩地、湖岸芦苇与水面倒影，另有林地与荒漠场景，配合晨昏色温、正午光照和夜间月星。全景直接作为整个花圃区域的背景，花圃和操作区叠放在同一场景中；背景随内容高度延伸，卡片使用半透明底保持文字可读。雨天按场景显示雨、雪或火山落灰，无外部图片请求。图鉴弹窗可以从委托或生态页直接打开，关闭后回到原入口。

## Discoveries and new regions / 发现提示与新地区

特殊收获、首次花卉发现、杂交种子、首次访客或特殊访客会打开**发现卡片**：大幅插画、明确标题、花色与奇珍标签、保存位置和图鉴入口。卡片不会自动消失，关闭后仍能从顶部「回看最新发现」打开；「设置与成就」保存最近 40 次发现。普通操作提示延长至 6.5 秒，并使用实色背景和更大文字。

地区扩展至六块：新增 **林地（1800 金币）** 与 **荒漠（2600 金币）**。旧存档会补齐为未解锁状态，原进度保留。每区仍有 6 个花圃，解锁时开放 3 个。

- 林地：毛地黄、蓝铃花、常春叶仙客来、林银莲花；林雨会湿润土壤，阴天生长较快。
- 荒漠：花菱草、沙漠金盏菊、钓钟柳、月见草；烈日促进生长，沙尘不会浇水。

「花卉图鉴」增加地区卡片，未解锁地区也可查看全部专属花卉的标准图和资料；收藏记录仍需实际发现。点击地区卡可以筛选图鉴或前往花园解锁。地区指南与当前种植地区分别管理，查资料不会切换花圃。新花资料见 [新增地区植物资料](docs/REGIONS.md)。

## Backpack and daily play / 背包与每日玩法

- **背包**：工具栏的「背包」把花、杂交种子和道具放进同一个格子界面。每格一个图标，右上角是数量，边框颜色表示稀有度（原色、别色、杂交、奇珍、仙品），仙品带流光，最稀有的排在最前。选中一格后右侧显示大图、估价和可用操作：花可以直接卖出或查看详情，洒水器和幸运符可以直接使用。数量为零的道具不占格子。
- **每日签到**：按本地日期每天领一次，七天一轮：金币、肥料、堆肥、洒水器，第七天是 100 金币加幸运符。漏签一天从第一天重新开始。
- **今日心愿**：每天从收获、播种、问候访客、交付订单、授粉里抽三项，完成后各领金币，三项全清再送肥料 ×2。
- **惊喜礼盒**：部分 20 分钟时段会在花园上方出现礼盒，点开得金币或道具，过时消失。
- **离开报告**：离开 5 分钟以上再回来，会看到一张卡片，写着离开了多久、新开了几株、几株缺水。
- **快捷道具栏**：花圃上方列出手头的道具。把肥料或堆肥拖到花圃上直接生效，也可以先点道具再点花圃；洒水器和幸运符点一下就用。
- **不打断的反馈**：领取奖励、收获和新发现不再弹窗，改为顶部提示条；花朵飞进背包、金币飞向余额。新发现仍记在「发现记录」里。离开报告 12 秒后自动收起。
- **音效**：在「设置与成就」里开启，默认关闭；用浏览器合成短音，没有音频文件。
- **地区配色**：每块花地有自己的主色，标签、主按钮和进度条跟着当前花地变。
- **生态研究**：三条研究分支画成两级节点的技能树，考察项目是带进度条的任务卡。
- **多窗口同步**：另一个窗口存档后，这个窗口会自动跟上，各自保留自己的标签页和花地。
- **插花台**：在「花篮」标签下方。从花篮里点 3 到 7 朵花放进花瓶，按配色和谐、三种以上、一朵主花、贴合今日主题色各加一星，一到五星。花束比散卖贵 6% 到 30%，不受同种花跌价影响，还给经验。
- **访客好感**：在「访客图鉴」标签顶部。问候一次好感 +1，送花 +2，送它偏爱的花再 +4，送杂交、奇珍或仙品再 +3。好感分四级，每升一级立刻得到金币或道具，之后每次问候的小费多 1 金币。
- **基因与育种**：每株花有色泽、色调、株高、花幅四条基因，各分五档，和画出来的样子一致；在背包详情和花朵详情卡里能看到。杂交种子会记住父母，后代的基因落在父母之间并偶有小突变；授粉后的花圃上会显示后代的预测范围。详情卡里有家谱，能看到父母和祖辈。
- **育种目标**：在「花卉图鉴」标签顶部，共七个，比如参天、袖珍、月白、三代同堂。收获自己育出的花时基因符合就立刻得奖，买来的种子不算。
- **真实季节与夜花**：按本地日期分春夏秋冬。当季的花仙品率 +1%，夜间开放的花在夜里再 +1%；反季节照常能种，没有惩罚。花园上方的小标签会写明当前季节和这块地的当季花。
- **采种远行**：在「委托」标签顶部。花金币派一支小队去已解锁的花地，1、4 或 8 小时后带回金币、杂交种子、道具，偶尔有绶带或幸运符；关掉页面也照常进行。
- **花瓶**：插花台有六种花瓶，靠插花数量解锁，鎏金瓶要插出一束五星。
- **收藏册**：在「花篮」标签下方。每完成一束花自动留下一张花束卡，最多 30 张；在背包里选一朵花点「做成花卡」，可以把它留下来而不是卖掉，最多 60 张，保留花色、奇珍和基因。
- **金币的去处**：花瓶、展示架格子、花坊工位都要花金币买，价格逐级上涨；远行、花束赛和加工也收费。
- **花瓶要买，也挑花**：花瓶先靠插花数量解锁，再花 300 到 6000 金币买下。圆肚瓶配花幅宽的花，长颈瓶配高株，藤编篮配四种以上混搭，月亮罐配素白，鎏金瓶配杂交、奇珍和仙品；半数以上相配，花束再贵 5%。
- **展示架**：在收藏册顶部，400 到 15000 金币逐格添置，最多五格。摆上去的卡才有加成：花束卡每星卖价 +1%，仙品花卡仙品率 +1%，杂交或奇珍花卡杂交率 +2%，其他花卡访客率 +1%。花园顶部会显示正在展示的卡。
- **卡片工具**：收藏册里每张卡可以存成图片（PNG，浏览器不支持时存为 SVG）；花束卡可以起名、题一句话。
- **卡册**：按花地、稀有度、奇珍统计收藏册里的花卡，集齐一页领一次奖励。
- **花坊**：在「花篮」标签下方。500、2000、6000 金币添置工位；干花、花茶、香水分别用 1、3、5 朵花，按原价计算不受跌价影响，成品值原价的 90%、100%、110%（仍高于跌到五成的市价），收工费并需要等待。
- **每周花束赛**：在「花展与设施」标签下方。每周送一张花束卡参赛，报名费 100 金币，和三位对手比分，第一名得 300 金币和 3 条绶带。
- **花园传承**：在「设置与成就」标签。等级 15 且六块花地全开后可以重新开始，保留收藏册、花瓶、展示架、图鉴、好感和最多三粒杂交种子；每传一代起始金币 +100，仙品率永久 +1%，最多 +5%。
- **每样材料都有用**：委托声望每满 10 点，远行小队多带回一样东西，最多三样。品种研究每升一级，该品种仙品率 +1%。绶带除了升级设施和提交考察，还能花 1 条让远行或花坊的一件成品立刻完成。插花、远行、加工、夺冠、基金、好感、育种目标和花卡的数量各有一个新成就。
- **十一个标签**：新增「工坊」（插花台、花坊）和「收藏册」（展示架、卡册、花束卡、花卡）两个标签，花篮标签只剩花篮本身。标签改成带图标的胶囊样式。
- **常驻伙伴**：在「访客图鉴」标签。好感满四级的访客可以花 1000 金币邀请住下，最多三位。传粉的每小时给一株花授粉，水岸的每小时把最干的一株浇透，护园的每小时给地力最低的花圃 +15。
- **花园奇遇**：部分半小时时段的前八分钟，花园上方会出现奇遇按钮：雨后彩虹（十分钟仙品率 +2%）、蜂群过境（当前花地全部授粉）、晨露降临（所有花浇透）、夜里的流星（幸运符生效）。
- **今日花束订单**：插花台顶部每天一张订单，要求星级、花朵数和主题色；当天第一束达标的花束额外得 60 金币和 1 条绶带。
- **花语贺卡**：收藏册里的花束卡点信封按钮，填上收件人，用花束里前两种花的花语拼成贺卡并存成图片。
- **每朵花都有用**：背包里选一朵花可以直接用掉，效果由它的生态角色决定：蜜源花让偏爱它的访客好感 +2，花粉花给当前花地一株花授粉，种实花换一份肥料，庇护花让当前花地每个花圃地力 +20，水岸花把当前花地浇透，夜花让仙品率五分钟内 +2%。杂交、奇珍和仙品效果加倍；用不上时不会消耗。
- **今日征花**：在「花篮」标签顶部。每天点名三种花，按顺序把已解锁花地的每一种花都轮一遍，全部 105 种约 35 天轮完。交一朵得两倍卖价加 10 金币，三种交齐再得 1 条绶带。
- **小窗的今日条**：悬浮小窗顶部多了一排快捷按钮，能直接签到、开礼盒、接奇遇、领心愿、交付征花、迎回远行小队、取花坊成品；另有「全部收获」和洒水器按钮。操作后小窗底部直接显示得到了什么，小窗配色也跟随当前花地。
- **花坊成品可以留着用**：做好的干花、花茶、香水可以「收下」进背包，也可以照旧直接卖掉。干花在插花时加一枝，花束多一颗星（最多五星）；花茶在访客好感里请一位访客喝，好感 +8；香水喷洒后全花园访客出现率 +15%，持续 30 分钟，不叠加。
- **花瓶颜色**：已拥有的花瓶可以在插花台改颜色，八个色板任选，也可以用取色器自己调，随时能恢复原色；免费。花束卡会记住插花时花瓶的颜色，之后再改色不影响旧卡。
- **一键收获与随机播种**：花圃上方那一排多了两个按钮。「一键收获」把当前花地开好的花全部收进花篮，留园的花不动，花篮满了就停；「一键问候」在当前花地有访客时出现，一次问候所有访客并收下小费；「随机播种」给每个空花圃随机种一种买得起的本地花，金币不够就停。小窗里也有。
- **多重奇珍**：一朵花可以同时带两到四种奇珍，名字和外观会叠在一起，比如「并蒂·霜晶雏菊」。已有奇珍的花，再得一种的几率依次降到原来的 25%、15%、8%，最多四种。换色的奇珍（虹彩、霜晶、熔火、珠光、墨玉）叠在一起时，各占花瓣的一段，底色取混合色。每多一种，卖价倍数再加 1（两种 ×3，四种 ×5），花展多得 1 分。
- **花园基金**：在「道具商店」标签顶部，是没有上限的金币去处。首级 2000 金币，每级贵 15%；每升一级得 1 条绶带，每逢第五级再得一枚幸运符，每五级换一个头衔。不返还金币，传承后保留。
- **玩法说明收进问号**：地力、杂交、售价、生态考察的规则不再整段铺在页面上，点区块旁的「?」展开。

## The loop / 玩法循环

1. **播种** — 在花地上选种子，扣金币，土壤浇水满。
2. **浇水** — 免费补满湿度；一次浇透大约能长到七成半，之后干了生长暂停。
3. **留园 / 收获** — 开花后可留作活株，持续观察、养护和复花；也可收进**花篮**（12 格），收获给经验。
4. **查看 / 卖出** — 点花篮里的花会展开这朵花的详情（大图、学名、花语、单价与合计），在详情里按当前花市报价卖出（点两次确认）；或凑成**花束委托**交付，拿更多金币。
5. **道具** — 金币买肥料、洒水器、幸运符，以及花篮扩容。 顶部常驻「道具背包」入口，展示四种道具、持有数量、使用方式与杂交种子；商店页也直接展示背包。研究升级、印记兑换、购买道具、考察与来信奖励通过金色全局弹窗展示，保留到手动关闭，可直接查看背包。
6. **开地** — 金币解锁新花地和新花圃。
7. **图鉴** — 每种花都能提前打开种植指南；首次收获或留园后记录真实标本；点卡片上的花或款式标签，可以打开花卉详情看这一款的活株外观（含学名、花语、收获次数）。
8. **访客** — 开着的花会引来访客，点它打招呼：拿小费并留下生态足迹；传粉访客授粉，护园访客恢复地力，水岸访客补充湿度。
9. **花市 / 成就** — 每天一种花卖价 +50%；二十四个成就按进度发金币。

## Living plants / 从花材到长期养成

- **留园**：成熟后选择「留园养成」，沿用花圃中已显示的花色与奇珍，保留同一株的 DNA。留园不占花篮，也不把花换成钱；普通收获按钮不能直接移除它，结束留园需再次确认。
- **慢养护**：留园株正常约 45 分钟才会干透；缺水不会死亡，只暂停观察与生态加成。浇水免费，洒水器同样有效。
- **品种研究**：湿度至少 30%、成熟、冷却结束时可观察；每株间隔 10 分钟，每次花费 `8 + ceil(种子价 × 0.25)` 金币，新增研究记录。每个品种独立达到 1 / 3 / 6 次后标记初识 / 熟悉 / 共生，之后仍可继续记录。
- **修剪复花**：已观察的活株可以支付 `10 + ceil(种子价 × 0.4)` 金币进入下一花期，从 35% 生长继续，原有外观、奇珍与个体不变。新一轮首次观察获得 2 条记录，其后为 1 条；复花不重置观察冷却。
- **生态搭配**：53 种花都配置蜜源、花粉、种实、庇护、水岸或夜访角色之一，另有主题花季与游戏访客偏好。角色多样性与当季活株最多增加 12 个百分点的访客出现概率；偏好访客在可出现候选中的权重 ×1.6。湿度不足 30% 的留园株不计生态加成。
- **循环考察**：每 6 小时一批 3 个项目，分别观察 3 / 4 / 5 种指定活株，并记录本期指定访客。目标基于期初已开花地固定，期内开新地不会改变任务。提交费用为 100 / 180 / 260 金币和 0 / 1 / 2 条绶带，获得 1 / 2 / 3 枚研究印记，不消耗花、不发金币，每项目每期一次。印记可消费，累计获得数仍保留，档案保存最近 100 条。
- **永久研究技能树**：生态研究页有养护、生态、育种三条分支，各两级，依次花费 3 / 6 枚研究印记。养护将观察与复花的金币费用减少 20% / 40%（费用向上取整）；生态额外增加 2 / 4 个百分点访客出现率，与花境、蜂箱叠加，总概率最高 85%；育种额外增加 5 / 10 个百分点杂交结种概率，与育种台叠加，最高 90%，仍需已授粉和邻株盛开。第二级为总效果，不与第一级重复计算。
- **印记兑换**：1 枚换肥料 ×2 或堆肥 ×3，2 枚换洒水器 ×1，3 枚换幸运符 ×1，可重复兑换并放入背包。解锁与兑换均需再次点击确认；旧档已有印记直接成为可用余额，永久技能和累计消耗随存档保存。
- **玩法边界**：角色加成、6 小时花季、养护费用和快速复花是游戏设定，并非真实植物的栽培日历。资料和来源见 [植物研究](docs/BOTANY.md) 与 [访客研究](docs/VISITORS.md)。

## Individual plants / 个体、育种与持续经营

- **每株独立外观**：播种生成固定的 DNA，高矮、朝向、倾斜、花瓣与色彩有细微差异；收获进花篮仍保留这株的外观，刷新不会重抽。
- **奇珍**：多次访客、多次施肥、缺水经历、特定天气或深夜盛开可能产生并蒂、巨株、斑锦、墨玉、霜晶、熔火、虹彩、珠光。条件只提供机会，不保证出现。花篮分开保存奇珍与普通花，支持组内个体切换和单株出售；送展也可选择具体植株。普通花束不会消耗奇珍或杂交花。
- **杂交种子**：已授粉的花收获时，左右相邻编号的花圃若有另一种盛开的花，基础 45% 概率结一粒杂交种子。种子保留母本株型、使用邻花颜色，在母本所属花地的播种列表免费播种。
- **地力**：每次收获消耗 14；连种同种再减 10，轮种其他品种加 8；空地每分钟恢复 1。贫瘠地块最低以正常速度的 55% 生长。商店的堆肥 25 金币一袋，在花圃使用恢复 60 地力。
- **花市饱和**：同种花每售出一朵，后续价格下降 5 个百分点，最低为原价 50%；每 2 分钟恢复一档。批量卖出逐朵报价，花篮和卖出使用相同算法；各分组报价是单独卖出价，全部卖出采用总报价。
- **花展**：每 6 小时一期主题展，最多送 8 朵。点击送展后再次确认，花会消耗并换评分，不发金币。达到 6 / 14 / 24 分时分别获得 1 / 2 / 3 条绶带，一届最多 6 条。
- **设施**：蜂箱提高访客概率，温室提高奇珍机会，育种台提高结杂交种子的概率。每种最高 8 级，价格按 ×1.8 增长，第二级起同时消耗绶带。消耗品、育种和周期花展提供持续目标；这不意味着金币总量有硬上限。
- **图鉴弹窗**：普通款式和已收集的奇珍、杂交花均可打开花卉详情，默认展示活株外观，查看学名、花语、植物知识与形成原因；支持切换条目、查看不同个体示例、Esc 关闭。新收获会保存该完整类型的首株真实标本（含 DNA、花色、奇珍和杂交组合），出售后仍保留；旧版只有计数的条目显示稳定的活株姿态示例，不会补造收藏 DNA。只有图鉴详情中单独点击「查看标本」才进入标本视图，可以点击「返回活株」退出。花园、花篮、发现卡和随身花园均默认展示活株。

## Special visitors and curiosities / 特殊访客与新奇珍

访客扩为 **13 种**。四种新增访客有独立插画、Wiki 来源和可点击的游戏出现线索；满足条件只是进入低权重候选池，不保证立刻出现。

- **欧洲熊蜂**：白天的草原、雪原、湖畔；湿度至少 50% 的盛开蜜源/花粉花，或三色堇。普通成熟花也可吸引。
- **金凤蝶**：晴天白昼的草原或湖畔，至少 3 种湿润盛开留园株，当前花为蜜源角色。
- **蜂鸟鹰蛾**：白天的草原、火山口或湖畔；湿润盛开的留园金鱼草、鸡蛋花、百合、火炬花或鲜红半边莲。它与夜行型天蛾是不同条目。
- **细扁食蚜蝇**：白天不下雨的草原或湖畔；湿润盛开留园株覆盖至少 2 种生态角色，当前株湿度至少 50%。成虫传粉，幼虫食蚜，两阶段角色不混用。

奇珍从 8 类扩到 **12 类**：新增缀化、辐射花冠、重瓣、花叶化。奇珍指南有独立示例画法、真实现象介绍和游戏获取条件。辐射花冠限制在金鱼草、鲜红半边莲、三色堇这些双侧花型；花叶化画出叶形和叶脉，区别于单纯绿色花。首次盛开时鉴定仙品与当时符合条件的奇珍，并直接改变花圃外观；之后新的访客或养护条件可继续触发尚未出现的奇珍，每种条件只尝试一次。已出现的形态保存在植株上，刷新、收获和留园不重抽；已有留园株复花保留原外观。

**真实形态不等于游戏因果**：施肥、访问次数和天气门槛是创作规则；现实中的缀化、花对称性改变或叶化有不同成因。霜晶、熔火等仍为幻想形态。逐项 Wiki 摘要与链接见 [特殊访客与植物奇珍资料](docs/SPECIAL-NATURAL-HISTORY.md)。

## Variants and the hidden bloom / 花色与隐藏款

每种花在图鉴里有 2~3 条款目：

| 款 | 怎么来 | 卖价 |
| --- | --- | --- |
| 原色 | 双数花圃开花 | ×1 |
| 别色 | 只在 **#1 / #3 / #5** 号花圃开花（15 种花有自然别色） | ×1.3 |
| 仙品（隐藏款） | 收获时随机触发 | ×3 |

仙品外形是**通体发光**的：珍珠白到淡紫的渐变花瓣、身后的柔光晕、缓慢自转的虚线圈、
四角星芒和上浮的光点（`prefers-reduced-motion` 下静止）。概率 = 基础 **1%**，再叠加：整株**从未缺水** +1%、在**本地偏爱的天气**里收获 +1%、
**刚浇过水**（湿度 ≥80%）+1%、**夜里**（22:00–05:00）收获 +1%，上限 **10%**。图鉴里会
写明这条线索。仙品不参与花束交付，可以卖出（基础 3 倍价，仍受行情与饱和影响）或送展。

## Limits / 说明

- The garden is stored in this browser's `localStorage` for the running profile
  (`dsh.flower-garden.v4`) and is shared by every session. It is not part of the
  session log, so it does not travel with a session export or a fork. A v1, v2 or v3
  garden is migrated on first load (coins, experience, plots, and every flower already recorded);
  a v4 garden saved before visitors and achievements simply starts those counters at zero.
- No model or tool requests, telemetry or background network access. Source links open their external sites only when clicked.
- Turning the plugin off removes the tab and keeps the saved garden.
- Progress is per browser: two windows that both show the garden follow each
  other's saves through the `storage` event; simultaneous actions still resolve last-write-wins.
- **Save files.** The footer's *Export save* downloads the whole garden as JSON;
  *Import save* reads one back after a confirmation click. The file carries the
  format and state versions, so a file from a newer build is refused instead of
  replacing the garden with defaults, and a v1–v3 file still imports through the
  same migration as a stored save. Your coins, plots, resident plants, basket,
  flower book, research and commissions all travel with it; nothing is uploaded.

花园进度保存在当前运行环境的浏览器 `localStorage`（`dsh.flower-garden.v4`），所有
会话共用，不写入会话日志，因此不会随会话导出或 fork 一起迁移。旧版存档
（v1/v2/v3）首次加载时迁移：金币、经验、花圃和已收集的花都会保留，旧记录记为「原色」。
插件不发任何模型请求、工具调用或后台网络请求；点击资料来源链接时会打开外部网站；关闭插件只会隐藏标签，花园数据仍然保留。

**存档文件。** 页脚的「导出存档」把整个花园下载成 JSON，「导入存档」读取后需要再点一次确认才会覆盖。
文件里带着格式与存档版本，来自更新版本的文件会被拒绝，不会用默认花园把现有进度冲掉；v1–v3 的旧档
同样走已有的迁移逻辑。金币、花圃、留园株、花篮、图鉴、研究与委托都会一起带走，文件不会上传到任何服务器。

## Development / 本地开发

```bash
npm install          # 只为跑测试和生成预览图（react / react-dom 是 devDependencies）
npm run build        # 把 src/ 下的片段按文件名顺序拼成 client.js
npm test             # 先检查 client.js 与 src/ 一致，再跑数值断言 + 静态渲染断言
npm run lint         # ESLint 检查构建出的 client.js、测试和工具脚本
npm run preview      # 用游戏同一套绘制代码重新生成 docs/preview.svg
```

项目结构：

```
package.json        bundle 清单（dsh.bundle + dsh.client）+ 测试脚本
cordis.patch.yml    插入 flower-garden 插件行
index.js            Host 半边：无行为，只负责让插件行可解析
client.js           浏览器半边的构建产物，不要直接改
src/NN-*.js         浏览器半边的源码片段：词典、物种、规则、存储、绘制、视图、样式、注册
tools/build.cjs     顺序拼接 src/ 生成 client.js（无打包器、无转换）
locale/*.json       插件管理页的标题 / 描述 / 详情文档
docs/               一张预览图（由同一套绘制代码生成）
test/               数值检查 + 渲染检查
tools/preview.cjs   预览图生成器
```

安装到 DSH：在 DSH 的 **设置 → 插件 → 添加插件** 里选择本目录（本地目录安装是
link）。本目录提供直接加载的 client.js；实际生效还取决于当前 DSH 的客户端构建与缓存，需在已运行的 DSH 页面刷新后验证。

The preview image in `docs/preview.svg` was generated from the same `FlowerArt`
code the view renders — one flower from each ground.
