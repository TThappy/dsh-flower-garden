# Botany notes for the next flower set

本文件只记录本轮扩展物种的植物学核对结果。资料主要来自 North Carolina Extension Gardener Plant Toolbox（NC State Extension），读取日期为 2026-11-16。四块花地是游戏里的生态主题场景，不代表这些植物的原生分布；游戏里的季节、生长时长和天气倍率也不应被理解为植物学日历。这里的“早春/夏季/夏秋”等均是北半球温带园艺资料中的描述。

## 草原 Meadow

- **波斯菊 / Cosmos bipinnatus** — 直立高茎，二回羽状蕾丝叶，粉、紫、白雏菊状头花；墨西哥及北美西南来源。NC State 标为蝴蝶、蜜蜂、鸟类和其他授粉者友好，耐旱、耐贫瘠土、长花期、可作切花并能自播。来源：[NC State](https://plants.ces.ncsu.edu/plants/cosmos-bipinnatus/)
- **百日草 / Zinnia elegans** — 墨西哥来源的一年生直立草本，夏秋连续开花，花头可大至巨大、颜色多样；适合全日照、排水良好的土壤。资料标注授粉者、蝴蝶和蜂鸟友好，耐旱、可作切花；页面还列出黄色染料用途。来源：[NC State](https://plants.ces.ncsu.edu/plants/zinnia-elegans/)
- **矢车菊 / Centaurea cyanus** — 欧洲和西亚来源的冷季一年生，蓝色约 1.5 英寸头状花，灰绿有毛的披针形叶；常见于田地、路旁和铁路边，耐旱、耐贫瘠，花和果为鸟类及蝴蝶食物，易自播自然化。花可食、可作切花；不要把它描述成北美原生。来源：[NC State](https://plants.ces.ncsu.edu/plants/centaurea-cyanus/)
- **金盏花 / Calendula officinalis** — 地中海来源的一年生，橙黄至红色花头，芳香叶；全日照、排水良好，春夏开花。页面确认花瓣可食、可作黄色染料，并吸引蝴蝶和授粉者；本游戏不把页面中的传统药用说法转成医疗功效。来源：[NC State](https://plants.ces.ncsu.edu/plants/calendula-officinalis/)
- **金鱼草 / Antirrhinum majus** — 西南欧来源；栽培多作一年生的短命多年生，终端总状花序上的两唇“龙嘴”花，花色丰富。喜湿润肥沃、排水良好土壤，耐旱性低；花可食、可作切花，蜜蜂需压开下唇取蜜，亦吸引蜂鸟和蝴蝶。来源：[NC State](https://plants.ces.ncsu.edu/plants/antirrhinum-majus/)

## 雪原 Snowfield

- **春番红花 / Crocus vernus** — 阿尔卑斯山、比利牛斯山和巴尔干地区来源的球根花卉，高约 10–15 cm；春季开花，花色可为紫、蓝紫或白，适合表现为低矮、杯状六瓣花和细长叶。现实中常见于草地、路旁和教堂墓地等开阔草地；这里采用 Wikipedia 的植物条目与其列出的皇家植物园爱丁堡资料链接作为基础综述来源，来源级别低于 NC State 植物工具箱。来源：[Wikipedia](https://en.wikipedia.org/wiki/Crocus_vernus)；[Royal Botanic Garden Edinburgh（条目列出的参考）](https://websites.rbge.org.uk/cgi-bin/nph-readbtree.pl?FAMILY_XREF=&GENUS_XREF=Crocus&SPECIES_XREF=vernus&TAXON_NAME_XREF=&RANK=)
- **黄水仙 / Narcissus pseudonarcissus** — 西欧来源的球根多年生；早春单花，冠筒与花被片相当或更长，线形基生叶。可自然化、耐热耐旱、抗虫病；页面明确花可提取黄色染料，同时指出鳞茎等部位含生物碱、有低度毒性，不能当食材。来源：[NC State](https://plants.ces.ncsu.edu/plants/narcissus-pseudonarcissus/)
- **报春花 / Primula vulgaris** — 西欧、高加索和黎巴嫩来源的多年生；基生皱叶莲座，冬末至早春开芳香浅黄小花，喜凉爽、湿润、半阴环境，可沿池塘溪流生长；页面标注吸引蜜蜂，并有低度毒性提示。来源：[NC State](https://plants.ces.ncsu.edu/plants/primula-vulgaris/)
- **三色堇（野堇菜）/ Viola tricolor** — 欧洲和亚洲来源、后引入北美；矮小一年生/二年生或短命多年生，紫、白、黄三色、带蜜距的两唇花，春夏开花，蒴果干燥时弹射种子。明确是紫斑蝶幼虫寄主，也吸引多种蜂、食蚜蝇和蝴蝶；花少量可食。来源：[NC State](https://plants.ces.ncsu.edu/plants/viola-tricolor/)
- **荷包牡丹 / Lamprocapnos spectabilis（旧名 Dicentra spectabilis）** — 西伯利亚、日本、中国北部和朝鲜来源；阴湿林地多年生，拱枝下垂心形花，三回复叶，春季开花后夏季地上部衰退休眠。吸引蜂鸟和蝴蝶，但全株有低度毒性、汁液可致皮炎；不能作为可食花。来源：[NC State](https://plants.ces.ncsu.edu/plants/lamprocapnos-spectabilis/)

## 火山口 Volcano

- **朱槿 / Hibiscus rosa-sinensis** — 亚洲来源的热带常绿木本灌木，4–10 英尺，深绿有光泽叶，直径可达 6 英寸的漏斗形花，中心有显眼的雄蕊柱；喜温暖、湿润、高湿和避霜环境。吸引蝴蝶、蜂鸟及专性蜂类，花可食；游戏中应作为热带活株观察，不当作旱地原生植物。来源：[NC State](https://plants.ces.ncsu.edu/plants/hibiscus-rosa-sinensis/)
- **天堂鸟 / Strelitzia reginae** — 南非来源的丛生热带多年生，地下根茎和香蕉状灰绿色大叶；橙色萼片与蓝色花瓣组成鸟头状花序，鸟类取蜜时花瓣会把花粉覆到脚上。可作切花，喜温暖明亮；果实和种子有低度毒性。来源：[NC State](https://plants.ces.ncsu.edu/plants/strelitzia-reginae/)
- **勋章菊 / Gazania rigens** — 南部非洲沿海来源的半耐寒多年生，低矮匍匐，橙黄雏菊花有深色基部；全日照、砂质排水土，耐旱耐贫瘠。花在夜间闭合，阴天可能不开；吸引蜜蜂和蝴蝶。来源：[NC State](https://plants.ces.ncsu.edu/plants/gazania-rigens/)
- **火炬百合 / Kniphofia uvaria** — 南非来源的丛生常绿多年生，剑形基生叶，4 英尺花葶上密集管状花序；花序由红色花蕾逐渐转黄，呈双色“火炬”。喜全日照、排水土，耐鹿和盐，吸引蜂鸟、蝴蝶及其他授粉者。来源：[NC State](https://plants.ces.ncsu.edu/plants/kniphofia-uvaria/)
- **沙漠玫瑰 / Adenium obesum** — 撒哈拉以南非洲和阿拉伯半岛荒漠来源的多肉多年生；膨大的块茎状茎（caudex）、灰绿肉质叶，夏季红粉白漏斗花。耐旱、喜全日照，常作盆栽或盆景；乳汁和全株有毒并可致皮炎，吸引蜂鸟和蝴蝶。来源：[NC State](https://plants.ces.ncsu.edu/plants/adenium-obesum/)

## 湖畔 Lakeside

- **沼泽金盏花 / Caltha palustris** — 北美原生的根茎多年生水生/湿地植物；春季空心分枝花茎上开 5–9 枚蜡质深黄花瓣状萼片，心形叶随后长大。需持续湿润、可耐积水，适合池边、雨水花园；吸引蜂和蜂鸟，生食有毒。来源：[NC State](https://plants.ces.ncsu.edu/plants/caltha-palustris/)
- **勿忘我 / Myosotis scorpioides** — 欧洲和亚洲来源的边缘水生多年生；湿草地、溪岸，约 10 英寸，天蓝色小花沿“蝎尾状”卷曲花序开放，能在浅水中生长并由根茎扩展。吸引小型蝴蝶和舞虻，也吸引蜂；在北美部分湿地自然化，可能成为有害杂草。来源：[NC State](https://plants.ces.ncsu.edu/plants/myosotis-scorpioides/)
- **中国落新妇 / Astilbe chinensis** — 中国、日本和朝鲜等东亚地区来源的多年生草本，约 45–90 cm；基生三出复叶，叶缘锐齿，花很小但聚成直立或弧形的羽状圆锥花序，整体像柔软的花羽。自然生境为阴湿溪流、河岸和湿润阔叶林边；园艺上用于阴生花园，需要土壤保持湿润。主要形态与生境依据 Wikipedia 条目，其参考资料列出 Missouri Botanical Garden 和 Kew POWO；这两条页面本次抓取分别失败/403，因此只采用条目中的基本信息，不扩展药用或烹饪用途。来源：[Wikipedia](https://en.wikipedia.org/wiki/Astilbe_chinensis)；[Missouri Botanical Garden（条目参考）](https://www.missouribotanicalgarden.org/PlantFinder/PlantFinderDetails.aspx?kempercode=h400)；[Kew POWO（条目参考）](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:790271-1)
- **红花半边莲 / Lobelia cardinalis** — 美国东部原生湿地多年生，高 4–5 英尺；夏末至中秋，鲜红二唇花从终端穗状花序底部向上开放。必须保持湿润，可耐短时淹水；是蜂鸟、蝴蝶及其他授粉者的重要花源，但全株中度毒性。来源：[NC State](https://plants.ces.ncsu.edu/plants/lobelia-cardinalis/)
- **欧洲慈姑（箭叶慈姑）/ Sagittaria sagittifolia** — 欧洲和亚洲湿地来源的多年生水生植物；生长在约 10–50 cm 深水中，出水叶呈明显箭头形，另有细长沉水叶；花序为分枝圆锥花序，白色三瓣花约 2–2.5 cm，带紫色雄蕊。游戏中可用“水面箭叶、沉水叶、白色三瓣花”区分；中文建议用“欧洲慈姑”或“箭叶慈姑”，避免与食用作物 **Sagittaria trifolia** 混称。基本形态、生境和生态资料来自 Wikipedia 条目，其参考资料链接到 Kew POWO；本轮 Kew 页面返回 403，故不把条目中有争议的食用、药用说法写入玩法。来源：[Wikipedia](https://en.wikipedia.org/wiki/Sagittaria_sagittifolia)；[Kew POWO（条目参考）](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:30074004-2)

## 资料边界与游戏使用

- 以上四块地是**游戏主题**：雪原可包含温带早春花，火山口可包含旱地或热带盆栽，湖畔可包含湿地植物；这不表示这些植物在同一现实地点共生。
- 真实北半球园艺页面的“冬末、早春、夏季、夏末至中秋”等描述只用于花的生态观察标签，不直接替代游戏内 6 小时花展周期。
- 新花应优先用于“活株观察、个体外观、生态关系、访客偏好、季节/昼夜/水分观察和图鉴”，不能默认把每朵花变成可消耗材料。毒性、自然化或湿地保护信息应以图鉴提示和栽培限制表现。
- NC State 页面未覆盖的三个指定物种已改用公开综述：Crocus vernus 和 Astilbe chinensis 使用 Wikipedia 条目（并保留条目列出的皇家植物园/园艺机构参考链接）；Sagittaria sagittifolia 使用 Wikipedia 条目及其列出的 Kew POWO 链接。它们仅用于基本形态、生境和生态观察标签，来源级别低于直接读取的 NC State 页面。
